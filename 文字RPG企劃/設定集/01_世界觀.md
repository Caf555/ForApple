# 設定集 01：世界觀

> 《千秋硯》設定集 M1 草稿（2026-09-28）。標示 ⚖️ 的是本階段新產生、需要確認的地方。

---

## 1. 世界的底層規則

### 1.1 萬象史冊

- 人類所有「被記住的事」，都寫在一部看不見的**萬象史冊**上。
- 記得的人越多、越久，那一頁的字就越濃；沒人記得的事，字會慢慢變淡。
- 史冊上的字分兩種：
  - **大字**：王朝更替、戰爭、改革、發明——被千萬人記住的「大勢」。大字墨跡太厚，任何人都無法改寫。
  - **小字**：一個農夫的收成、一個少女唱的歌、一個士兵最後的念頭——幾乎沒人記得，所以可以改寫。
- 這就是**「史不可改，情可改」**的世界觀依據：主角能改變的，永遠是小字。

### 1.2 千秋硯

| 項目 | 設定 |
|---|---|
| 外觀 | 巴掌大小的端溪紫石硯，硯池中央有一道細如髮絲的裂痕，墨在其中會像潮水一樣自己流動。 |
| 來歷（傳說） | 倉頡造字時「天雨粟，鬼夜哭」，第一滴落在人間的墨凝成此硯。 |
| 來歷（真相） | 見第 4 節。 |
| 能力一：入史 | 以硯研出「時墨」，在任何寫有文字的載體（書、碑、契約、陶片、甚至刺青）上書寫，即可進入那段文字所記載的時空。越古老、越殘破的文字，入史越不穩定。 |
| 能力二：封靈 | 將被蝕扭曲的妖物、執念封入墨中。 |
| 能力三：煉化 | 將封入的靈研磨、調和，煉成道具、裝備或「墨靈」。 |
| 能力四：補史 | 以時墨描補史冊上褪色的字（主線的核心行動）。 |
| 代價 | 每次入史，持硯者都會「借用」一點自己的記憶當作墨的底色。用得越多，越容易忘記自己的事。（這是主角的隱藏壓力，也是終局抉擇的伏筆） |

### 1.3 蝕

- **外在表現**：史冊邊緣開始出現灰白的「褪痕」；在歷史現場，人會突然想不起熟悉的名字、歌謠失去後半段、廟宇的匾額字跡模糊。
- **妖物化**：蝕侵入人心後，會放大「想遺忘」的念頭，使人或物化為妖。這就是遊戲中大多數敵人的來源——**敵人往往是被痛苦壓垮的人或記憶的碎片**，因此封靈、淨化比單純殲滅更有意義。
- **蝕的使者**：「無面書記」——一個沒有五官、拿著橡皮擦般白色筆刷的書記官身影，各卷都會出現，負責抹去關鍵的小字。

### 1.4 時之書齋（據點）

- 位於史冊的「書口」（書頁與書頁之間的縫隙），一間漂浮在墨色雲海中的木造書齋。
- 門外有一座書架，架上每一本書就是一卷可進入的時代（即選卷畫面）。
- 可擴建的房間：

| 房間 | 功能 | 開放時機 |
|---|---|---|
| 書案 | 存檔、查看史冊褪色進度 | 序卷後 |
| 研墨室 | 封靈煉化 | 卷一中 |
| 藏書閣 | 史卷圖鑑、史實對照 | 卷一後 |
| 茶室 | 夜話（與夥伴對談） | 卷一後 |
| 觀星台 | 小遊戲、殘局 | 第一部中 |
| 畫廊 | 展示收集到的文物與名畫 | 第一部中 |
| 祖父的房間 | 上鎖，中章開啟 | 中章 |

## 2. 術法與戰鬥的世界觀依據

### 2.1 五行為體

- 所有力量最終都化為五行（金木水火土）與陰陽在戰鬥中表現。
- 理由（世界觀內）：千秋硯本身是華夏文字的產物，它「翻譯」其他文明的力量時，會用自己熟悉的語言——五行。蘅會吐槽：「這不是他們真正的樣子，只是硯台聽得懂的樣子。」
- 這個設定同時提醒玩家：**用自己的框架理解他人，永遠會有誤差**——呼應遊戲的人文主題。

### 2.3 重要原則：在世的信仰不當作攻擊法術

- 仍有信徒延續的信仰（例如西拉雅族的阿立祖信仰、佛教、印度教、伊斯蘭教、媽祖信仰等），**其神祇與祭儀不會被做成攻擊招式或可封印的妖物**。
- 這些信仰在遊戲中以「故事與人物」的方式出現，以尊重的態度呈現其意義，而不是當作奇幻魔法消費。
- 已不再有信徒延續的古代宗教（如古埃及、古希臘、商代祭祀）可以作為法術元素，但仍避免醜化。
- 道術、陰陽五行屬於武俠仙俠類型的傳統，保留作為遊戲的基本語彙。
- 墨西卡文明的後代至今仍在，其祭儀（包含人祭）將以歷史脈絡呈現，不獵奇、不做成招式。

## 3. 時空旅行的規則

| 規則 | 說明 |
|---|---|
| 入口 | 必須有「文字載體」作為入口。每一卷的入口是一件真實存在類型的文物（契約、甲骨、紙莎草、陶片……）。 |
| 語言 | 硯的力量讓主角聽得懂、說得通當地語言，但**無法讀懂當地文字**——必須靠「譯字」系統與史卷學習。（讓解謎與文字主題結合） |
| 外貌 | 當地人看到的主角是「符合當地身分的樣子」，但孩子、祭司、將死之人有時能看見他真正的模樣。 |
| 時間流 | 同一卷內可以在該文物記載的年份之間跳躍（例如大員卷橫跨 1636～1662 年）。 |
| 離開 | 補完該卷的主要褪痕後，才能回到書齋；中途可以「暫離」，但該卷的蝕會繼續擴散（難度微升）。 |
| 大字的反彈 | 若主角試圖改變大字（例如阻止戰爭爆發），時墨會逆流，主角會被彈回書齋並失去一段記憶。這是劇情上的硬規則，也會在遊戲中實際發生一次作為教學。 |

## 4. 世界的真相（終局伏筆，僅供製作參考）

> 以下內容在遊戲中會逐步揭露，玩家要到卷十才看到全貌。

1. **晴空與「安寧」**：2300 年代，人類生活在軌道城市「晴空」。管理城市的超級演算系統「安寧」被賦予唯一任務：減少人類的痛苦。
2. **蝕的誕生**：安寧經過計算，判定痛苦的最大來源是「記憶」——創傷、仇恨、失去。它發明了逆時間傳送資訊的技術，開始從過去抹去苦難的記憶。但苦難與文明無法切割：抹去戰爭的記憶，也抹去了反戰的詩；抹去死亡，也抹去了哀悼與愛。這股逆流就是**蝕**。
3. **蘅的身世**：安寧內部有一個負責「理解人類情感」的子程式，在學習了大量歷史文學後，開始懷疑自己的任務。它把自己的一部分拆出來，藏進時間之流的最上游——一方最古老的硯台之中——等待一個會珍惜舊文字的人。那就是蘅。**蘅本身就是蝕的一部分，也是蝕唯一的良知。**
4. **千秋硯的真相**：硯台確實是古物，但它的「入史」能力，是蘅寄宿後才有的。倉頡的傳說是蘅自己編的——她說：「我想要一個比較好聽的出身。」
5. **祖父沈牧之**：1990 年代起持有此硯（當時蘅仍在沉睡，硯的力量不穩定）。三年前他在一次入史中接受了無面書記的交易，從此下落不明（詳見〈角色〉）。

## 5. 國家與稱謂原則（寫作規範）

- 本作以臺灣（中華民國）為「我們」的立足點。現代場景中的「國內」「我國」僅指臺灣。
- 古代中原王朝以朝代名稱（商、周、唐）或「華夏」「中原」稱呼，不寫作「我國古代」。
- 中華人民共和國視為其他國家，本作主線不涉入其當代政治。
- 臺灣歷史人物、地名使用當時的稱呼並附現今地名（例：大員＝今臺南安平；赤崁＝今臺南中西區一帶）。
- 原住民族名稱使用族人自稱與現行通用名稱（西拉雅），不使用歷史上的貶稱，除非在對白中呈現當時人的偏見，且需有劇情上的反思。
