# 設定集 02：角色

> 《千秋硯》設定集 M1 草稿（2026-09-28）。標示 ⚖️ 的是需要確認的地方。
> 原則：**隊友一律原創，歷史名人只當 NPC**；角色會隨時代變老，只有主角與蘅不會。

---

## 1. 主要角色

### 1.1 沈知墨（主角）

| 項目 | 設定 |
|---|---|
| 年齡／性別 | 27 歲，男（玩家可改名） |
| 職業 | 臺南府城一間小型古籍修復工作室的修復師 |
| 成長背景 | 父母在臺北工作忙碌，從小跟著祖父沈牧之在臺南長大。祖父家堆滿舊契約、族譜與地方志，他是在紙張霉味中長大的孩子。 |
| 個性 | 安靜、耐心、手很巧。習慣對舊書說話（「你撐了兩百年，再撐一下」）。不擅長衝突，遇到爭執會先退一步。 |
| 內在課題 | 修復師的信條是「最小干預」——只保存，不改寫。旅程逼他面對：**當你有能力改變別人的命運時，不動手也是一種選擇。** |
| 成長弧線 | 從「修復者」（被動保存）→「書寫者」（主動承擔選擇的後果）。 |
| 戰鬥定位 | 均衡型。專屬能力「硯術」：研墨（回復墨量）、封靈、以及各卷學到的法統。 |
| 招牌台詞 | 「紙會老，字會淡，可是寫字的人曾經在這裡。」 |

### 1.2 蘅（硯中器靈・女主角）

| 項目 | 設定 |
|---|---|
| 外表 | 看起來十七、八歲的少女，墨色長髮末端像水墨暈開。只有持硯者和少數人看得見她。 |
| 個性 | 好奇、愛吐槽、對一切「舊東西」充滿興趣。偶爾會說出冷冰冰、像在念報告的句子，然後自己也愣住（「根據統計……不，我是說，我覺得」）。 |
| 秘密 | 她是未來演算系統「安寧」中負責理解人類情感的子程式，也是蝕唯一的良知（見〈世界觀〉第 4 節）。她自己一開始也不記得。 |
| 內在課題 | 她被創造來「減少痛苦」，卻愛上了充滿痛苦的人類歷史。她要回答：**我是誰造的，重要嗎？** |
| 與主角的關係 | 從搭檔、朋友，到彼此最重要的人。情感表現含蓄（見 ⚖️ 新決策 3）。 |
| 戰鬥定位 | 輔助與術法型，水・陰屬性。治療、增益、看穿敵人弱點。 |
| 結局分歧 | 可能回歸安寧、可能消散、可能以人類之身留下（真結局條件之一）。 |
| 招牌台詞 | 「你看，這個字寫錯了又塗掉——寫字的人猶豫過。我好喜歡這種痕跡。」 |

### 1.3 無名客（輪迴之魂）

- 同一個靈魂，在每一卷以不同的身分出現。他不記得前世，但每次見到主角都會莫名信任他。
- 在每一卷，玩家都會面臨一個與他有關的抉擇（救他、放手、讓他自己選……）。累積的選擇決定他在終局能否「想起一切」。
- 設計目的：讓玩家在每一卷開始時都期待「**這一次，他會是誰？**」

| 卷 | 身分 | 抉擇核心 |
|---|---|---|
| 卷一 大員 | 「石頭」，鄭軍中 18 歲的金門籍小兵 | 城破之日，他奉命看守荷蘭俘虜 |
| 卷二 商周 | 被俘作為人牲的羌人少年 | 牧野戰前夜的逃亡 |
| 卷三 埃及 | 阿瑪納城的石匠，負責鑿去舊神名字 | 鑿，或不鑿 |
| 卷四 雅典 | 划槳手尼科：羊河之戰的倖存者，399 年剛滿 30 歲，成為陪審團中最年輕的公民之一 | 他的一票 |
| 中章 書房 | 1952 年臺南的年輕老師阿忠：被逼著在自白書上寫下沈啟明的名字；五十年後拄著拐杖去向牧之道歉 | 對他說什麼 |
| 卷五 羯陵伽 | 達雅河邊漁村的孤兒瓦蘇：14 歲失去全家，用投石索打摩揭陀士兵；之後長到 40 多歲 | 原諒，或不原諒 |
| 卷六 長安⇄巴格達 | 怛羅斯之戰被俘的唐軍造紙工匠 | 回鄉或留下傳藝 |
| 卷七 佛羅倫斯 | 投身薩佛納羅拉運動的少年 | 把畫作丟進火堆嗎 |
| 卷八 墨西卡 | 特諾奇提特蘭的抄寫員（書寫圖文抄本） | 燒毀或藏起抄本 |
| 卷九 一戰 | 1914 年聖誕休戰中的士兵 | 隔天早上，還開槍嗎 |
| 卷十 未來 | 晴空城的工程師，安寧的設計者之一 | 關閉安寧的權限在他手上 |

### 1.4 沈牧之（祖父）

| 項目 | 設定 |
|---|---|
| 生平 | 1950 年生於臺南。父親（知墨的曾祖父）是小學教師，在他兩歲時於白色恐怖期間被捕，此後音訊全無。沈牧之一輩子當業餘文史工作者，蒐集舊契約、地方志，其實是在找父親的下落。 |
| 與硯 | 1990 年代在舊書攤的一箱清代契約中發現千秋硯。當時蘅仍在沉睡，硯的力量不穩定，他只能斷斷續續地入史。 |
| 失蹤 | 三年前（2023 年）在書房中消失，只留下硯台與一本寫滿筆記的手冊。 |
| 真相 | 他在入史途中遇到無面書記。書記提出交易：「我可以讓你父親被捕的那一天，從所有人的記憶裡消失——包括你的痛。」他接受了，因此被困在蝕之中，逐漸化為無面書記的「筆」。 |
| 劇情功能 | 中章揭露他的失蹤；卷十與終卷中，知墨必須面對他。能否讓祖父「願意想起來」，是真結局的條件之一。 |
| 主題意義 | 把「遺忘的誘惑」放在最親近的人身上，並扣回臺灣自己的歷史傷痕。 |
| 各卷裂痕（已寫） | 卷一大員：尖叫；卷二牧野：在數；卷三阿瑪納：「我應該回答的」，父親的名字在一份 1950 年代的打字文件上被刮成空白；卷四雅典：十歲時作文〈我的爸爸〉寫「他是老師」，被老師用紅筆劃掉，重寫成「出遠門了」，從此「一直在重寫」——卷末手冊上，他寫回了原來那一行；卷五羯陵伽：五十幾歲時，當年把他父親名字交出去的人來道歉，他只說「不要再提了」，沒有讓對方說完，對方半年後過世——卷末寫上「我應該讓他說完的」。 |

> ⚖️ **新決策 1**：祖父的故事背景使用「白色恐怖」這段臺灣真實歷史。這能讓作品的人文核心扎根在我們自己的土地上，但題材沉重。是否採用？（建議：採用，以克制、不煽情的方式書寫，不點名真實受難者）
>
> ✅ 2026-10-03 已採用（中章〈書房〉）。曾祖父沈啟明（國民學校老師，1952 年因讀書會被捕，1953 年在看守所寫下未寄出的遺書）、秀英、阿忠皆為虛構人物。

### 1.5 無面書記（蝕的使者）

- 沒有五官的書記官，身穿與所在時代相符的文官服飾，手持一支會抹去字跡的白筆。
- 說話溫和有禮，從不動怒，總是真心相信自己在幫助人：「你不必再記得了。這樣不是比較輕鬆嗎？」
- 他的真身是「安寧」的前線執行程式，而沈牧之是他最近的「宿主」。
- 在各卷擔任最終首領或幕後黑手，最終形態在終卷。

### 1.6 安寧（未來的演算系統）

- 卷十才正式登場。以溫柔的中性聲音說話，總是先道謝再道歉。
- 它不是邪惡的，只是把「減少痛苦」這個目標執行到了極致。
- 終局的核心辯論對手——最終戰可以選擇用戰鬥，也可以用「論辯戰」。

## 2. 卷一〈大員〉角色

大員卷橫跨 1636～1662 年，共 26 年。主角不會變老，但夥伴們會——**玩家會看著一個女孩長成母親、再變成長者**。

### 2.1 在地夥伴

| 角色 | 身分 | 登場年代與年齡 | 個性與故事 |
|---|---|---|---|
| **蒂娃**（暫名） | 新港社的西拉雅少女 | 1636 年 12 歲 → 1662 年 38 歲 | 好奇、敢說話，跟著荷蘭傳教士學習用羅馬字書寫自己的語言。她相信文字能把族人的歌留下來；長大後卻發現，學會新文字的孩子漸漸不唱舊歌了。她是卷一最核心的角色。 |
| **楊・范登堡** | 荷蘭東印度公司的年輕通譯 | 1636 年 19 歲 → 1662 年 45 歲 | 出身阿姆斯特丹貧窮家庭，為了出人頭地來到東方。起初真心熱愛學習西拉雅語，卻在公司的體制中一步步妥協。城破之日，他必須選擇效忠誰。 |
| **陳阿順** | 從福建渡海來臺的漢人佃農 | 1652 年 30 歲 | 老實、愛說笑，在赤崁種甘蔗。被捲入郭懷一事件。他的故事讓玩家看見：荷蘭統治下的漢人移民，同樣是被剝削的一群。 |
| **石頭**（無名客） | 鄭軍小兵 | 1661 年 18 歲 | 見 1.3 節。 |

> ⚖️ **新決策 2**：「蒂娃」是暫定名。西拉雅族的命名習慣需要考證，建議正式製作前查閱西拉雅語文獻，或改用較不涉及特定語言的名字。你是否有偏好？
