# 《千秋硯》劇本語法說明

> 給想自己寫劇情的人。不需要懂程式，只要會打字。
> 劇本檔案放在 `千秋硯/content/` 資料夾，副檔名是 `.txt`。

---

## 1. 最基本的三件事

### 場景

每一段劇情都是一個「場景」，用 `#` 開頭，後面接場景名稱：

```text
# v1.1.學堂
```

場景名稱不能重複。建議用「卷.回.地點」的方式命名，例如 `v1.2.祖母`。

### 旁白與對白

```text
學堂裡坐著二十幾個孩子。             ← 直接寫，就是旁白
【蒂娃】我叫蒂娃，住在新港社。        ← 【名字】開頭，就是對白
【旁白】這樣寫也是旁白。
```

- 每一行，玩家要點一下才會出現下一行。
- 寫 `{名}` 會自動換成主角的名字（預設「知墨」）。`{暱}` 會換成暱稱（預設「阿墨」）。
- 主角的對白一律寫 `【知墨】`，遊戲會自動換成玩家取的名字。

### 選項與跳轉

```text
？ 去學堂看看 → v1.1.學堂
？ 去蒂娃家 → v1.1.蒂娃家
```

- `？` 開頭是選項，`→` 後面是要跳去的場景。連續寫的選項會一起出現。
- 單獨一行 `→ 場景名稱`，就是直接跳過去。

---

## 2. 條件

選項前面可以加條件，用全形方括號 `［ ］` 包起來：

```text
？［旗標 v1.學堂］回學堂找楊 → v1.1.譯字
？［羈絆 蘅 ≥ 2］握住她的手 → v1.1.握手
？［心印 情 ≥ 40］什麼都不說，只是陪著他 → v1.1.陪伴
？［中庸］兩個都做 → v1.1.兩者
```

| 條件寫法 | 意思 |
|---|---|
| `旗標 名稱` | 某件事發生過 |
| `旗標 名稱 = 值` | 某件事的結果是某個值 |
| `非 旗標 名稱` | 某件事**沒有**發生過 |
| `羈絆 角色 ≥ 數字` | 和某角色的羈絆等級 |
| `心印 情 ≥ 數字` | 心印偏向「情」多少（可用：情、理、剛、柔、出世、入世） |
| `中庸` | 三條心印軸都在 ±30 以內 |
| `道具 名稱` | 持有某道具 |
| `史卷 名稱` | 收錄了某史卷條目 |
| `靈 名稱` | 硯池裡有某個靈 |

- 多個條件用「且」連接：`［旗標 v1.學堂 且 旗標 v1.蒂娃家］`
- 只用「旗標」當條件的選項，條件不符時會**隱藏**（劇情還沒到）；其他條件不符時會**上鎖**，讓玩家知道還差什麼。

### 條件跳轉

```text
◆ 若 旗標 v1.歌 = 書寫 → v1.2.重逢書寫
◆ 若 旗標 v1.歌 = 口傳 → v1.2.重逢口傳
→ v1.2.重逢兩者
```

由上往下檢查，符合就跳走；都不符合就繼續往下。

## 3. 效果（改變遊戲狀態）

`+` 是增加，`-` 是減少或移除。

| 寫法 | 效果 |
|---|---|
| `+旗標 v1.學堂` | 記下「這件事發生了」 |
| `+旗標 v1.歌 書寫` | 記下「這件事的結果是：書寫」 |
| `+羈絆 蘅 5` | 蘅的羈絆 +5 點 |
| `+心印 情 10` | 心印往「情」偏 10 |
| `+道具 草藥 3` | 取得 3 個草藥 |
| `+錢 50` | 取得 50 銀 |
| `+經驗 30` | 全隊獲得 30 經驗 |
| `+史卷 新港社` | 史卷收錄「新港社」 |
| `+隊友 蒂娃 等級 6` | 蒂娃以 6 級加入隊伍 |
| `-隊友 蒂娃` | 蒂娃離開隊伍（不在隊伍裡就什麼都不做；加「無提示」不顯示提示） |
| `+封靈 失語之影` | 把某個靈直接放進硯池 |
| `+陣法 雁行陣` | 習得陣法 |
| `+技能 知墨 雙語對照` | 角色習得技能 |
| `+補史 v1.新港之歌` | 修補一頁史冊（計入修復率） |

## 4. 戰鬥

```text
⚔ 戰鬥 v1_褪聲鬼 → 勝：v1.1.歌回
⚔ 隨機 新港田野 → 勝：v1.1.田野後
⚔ 戰鬥 某敵人組 → 勝：打贏的場景　敗：打輸的場景
```

- `戰鬥` 後面是固定的敵人組，`隨機` 後面是遭遇池（從幾組敵人中隨機一組）。
- 沒寫「敗」的話，輸了會出現「重新挑戰」的畫面。
- 敵人組與遭遇池定義在 `千秋硯/js/data.js`。

## 5. 演出與系統指令

| 寫法 | 效果 |
|---|---|
| `@章節 卷一　大員｜回一　新港的字` | 全螢幕章節標題卡（｜前是標題，後是副標） |
| `@卷 卷一・大員` | 頂部顯示的卷名 |
| `@地點 新港社` | 頂部與場景圖上的地點 |
| `@年代 1636 年` | 頂部與場景圖上的年代 |
| `@主題 dayuan` | 切換視覺主題（modern 現代／dayuan 大員／muye 牧野／amarna 阿瑪納／hub 書齋） |
| `@音樂 海潮` | 切換氛圍音樂（府城夜、海潮、書齋、緊張、哀歌、戰鬥、首領、殷商、阿瑪納、無） |
| `@清畫面` | 清除畫面上的文字 |
| `@回復` | 全隊體與墨完全回復 |
| `@提示 文字` | 畫面上方跳出小提示 |
| `@教學 第一段／第二段` | 跳出說明視窗，用「／」分頁 |
| `@進度 場景名稱` | 記下這一卷的續玩點（回到書齋後從這裡繼續） |
| `@回書齋 場景名稱` | 回到時之書齋，並把續玩點設為該場景 |
| `@開放 研墨室` | 開放書齋的房間 |
| `@商店 漢人商販` | 開啟商店 |
| `@論辯 楊_教育 → 說服：A　人心：B　和解：C　敗：D` | 論辯戰，依結果跳往不同場景 |
| `@小遊戲 譯字 荷蘭語一 → 勝：A　敗：B` | 問答小遊戲。種類有 譯字、牽星、識字（甲骨文、聖書體，字形用筆畫畫出） |
| `@取名` | 讓玩家輸入主角名字 |
| `@稱呼 摩斯 阿蒙摩斯` | 暫時改變角色在對話與戰鬥中顯示的名字（例如改名之前）；`@稱呼 摩斯 預設` 恢復 |
| `@試玩結束 場景名稱` | 顯示試玩結束，並設定之後的續玩點 |

## 6. 註解

`//` 開頭的行是給作者看的註解，遊戲不會顯示。

---

## 7. 寫完之後：檢查

在 `千秋硯` 資料夾執行：

```bash
node tools/check.mjs
```

它會用中文告訴你哪一個檔案、第幾行有問題，例如：

```text
✗ content/卷一_大員.txt 第 120 行：找不到場景「v1.1.學當」
✗ content/卷一_大員.txt 第 88 行：沒有道具「草葯」
```

新增劇本檔案時，記得把檔名加進 `千秋硯/js/main.js` 最上面的 `CONTENT` 清單，以及 `千秋硯/sw.js` 的離線快取清單。
