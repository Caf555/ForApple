## 1. 設計目標

1. **好奇心驅動**：玩家最常想的一句話是「再往前一格看看」。
2. **每一步都有取捨**：補給有限，霧會回來，不能什麼都要。
3. **看得見的成果**：地圖越畫越大、港口越來越熱鬧、隊友越來越強。
4. **短時間也能玩**：一座小島 15～25 分鐘可以走完，適合手機。
5. **故事是調味，不是主菜**：劇情節奏明快，對話短；世界觀藏在地圖、遺跡與道具說明裡，讓想挖的人自己挖。

不做的事：
- 不做即時動作戰鬥、不做 3D、不做連網功能與抽卡。
- 不使用真實民族、宗教、地名當作設定；世界觀完全原創。

## 2. 世界觀

### 2.1 霧之群島
- 一片沒有大陸的海，散布著上百座島。三百年前，「白霧」從海的中心升起。
- **霧的規則**：沒有被畫進地圖的地方，會慢慢被霧吞掉——不是被遮住，而是**被遺忘**，連住在那裡的人都會忘記自己的島。
- 被正確畫進「繪圖師之書」的地方，霧就進不來。
- 從前有一個「繪圖師公會」，守護群島兩百年。五十年前，公會在一夜之間消失了。

### 2.2 主角（外型固定）
- 公會最後一位學徒的孩子，在一座快被霧吞掉的小漁島長大。名字預設「墨里」，玩家可以改。
- **外型定案**：17 歲的少女。黑色短髮，右邊有一撮被霧染白的頭髮；左眼是淡灰色，看得見霧裡的東西。深藍色、口袋很多的舊航海外套，斜背一個皮包，裡面是繪圖師之書；耳後夾著一支會發出淡光的筆。表情安靜、觀察很仔細。
  - 群島的人稱繪圖師為「畫海人」，這也是書名的由來。
- 開場：母親留下一本**空白的繪圖師之書**和一支會發光的筆。島上的人開始忘記彼此的名字，主角決定出海。
- 外型固定，但說話的態度由玩家的選擇決定（大方向：大膽／謹慎；溫柔／務實）。

### 2.3 神祕感的寫法
- **霧會說話**：在霧中走得越久，畫面邊緣會出現低語文字（被遺忘的人說過的話），有時是線索，有時是陷阱。
- **每座島一個祕密**：例如全村的人每天早上醒來都不記得昨天；燈塔守了五十年，卻沒有人知道它在等誰。島主戰就是祕密揭開的時刻。
- **少說明，多留白**：世界觀不用一大段文字交代，而是藏在遺跡的碎片、道具說明和霧中的低語裡。
- **溫暖留給隊友**：營地夜談是唯一放鬆的時刻，讓玩家在冷冽的霧裡有可以依靠的人。

### 2.4 三大勢力
| 勢力 | 立場 | 想要什麼 | 玩家能得到 |
|---|---|---|---|
| **銀貝商會** | 務實的商人聯盟 | 安全航線與貿易，把所有島「登記入冊」收稅 | 金錢、補給、船的改造 |
| **守霧人** | 住在霧邊緣的隱士 | 相信霧有它存在的理由，反對「畫掉」一切 | 霧中行動的能力、祕密航道 |
| **紅帆海盜** | 被商會趕出港口的人 | 自由，以及被商會奪走的島 | 戰鬥夥伴、黑市、捷徑 |

玩家可以和三方都打交道，但重要節點必須選邊；聲望會影響委託、商店與結局。

### 2.5 霧的真相（只給製作方看，劇透）
- 霧是群島「遺忘的力量」被放大的樣子。三百年前，海中心的古王國為了忘掉一場災難，祈求「讓痛苦的地方消失」，結果失控。
- 繪圖師公會其實知道真相；五十年前，公會長打算「把整片海畫完」來消滅霧，代價是群島所有的「未知」也一起消失（不能再有新的島、新的傳說）。公會內部分裂，公會長帶著反對者沉入霧心。
- 主角的母親是反對者之一。
- 主題：**地圖不是為了佔有世界，而是為了記得它；也要留一些空白給後來的人。**

### 2.6 結局（4 種）
| 結局 | 條件（草案） | 內容 |
|---|---|---|
| 一、晴海 | 商會聲望最高，霧心戰選擇「畫完」 | 霧消散，群島繁榮，但再也沒有新的島嶼出現 |
| 二、與霧同行 | 守霧人聲望最高，選擇「封印霧心」 | 霧留下來，但只吞沒「沒人愛的地方」；繪圖師成為守門人 |
| 三、自由之海 | 海盜聲望最高，選擇「把書交給所有人」 | 每個人都能畫地圖，群島混亂而熱鬧 |
| 真・留白 | 三方聲望都達標、8 名隊友個人任務完成、總地圖完成度 90% 以上 | 主角在地圖的正中央留下一塊空白，霧化為海上的晨霧；母親的身影出現在空白的邊緣 |

## 3. 核心循環

```
        ┌──────────────── 港口（據點）────────────────┐
        │ 接委託・補給・組隊・打造裝備・建設港口       │
        └───────────────┬────────────────────────────┘
                        ▼
              出航（航海事件 1～3 個）
                        ▼
        ┌──────────── 島嶼探索（一張格子地圖）───────────┐
        │ 每走一格消耗糧食；揭開霧；遇到戰鬥、事件、寶藏 │
        │ 到「測繪點」完成測繪 → 這一區永久留在地圖上     │
        │ 打倒島主或找到出口 → 完成這座島                 │
        └───────────────┬───────────────────────────────┘
                        ▼
        回港：結算戰利品、把這座島畫進總地圖、劇情推進
```

- **短循環**（約 1 分鐘）：走一格 → 看見新東西 → 決定下一步。
- **中循環**（15～25 分鐘）：一座島從出航到回港。
- **長循環**（每個海域 3～5 小時）：解鎖新海域、港口升級、勢力劇情。

## 4. 系統設計

### 4.1 島嶼探索
- **地圖**：每座島是一張六角格地圖（小島 5×5、大島 9×9），一開始全被霧蓋住，只看得見周圍一格。
- **格子種類**

| 記號 | 名稱 | 內容 |
|---|---|---|
| 怪 | 戰鬥 | 一般戰鬥；看得見大概強度（一顆到三顆星），可以繞路 |
| 眼 | 霧眼 | 精英戰鬥；打贏可以把周圍兩格的霧一次驅散 |
| 寶 | 寶箱 | 素材、裝備、地圖碎片；有的上鎖，要特定隊友或工具 |
| ？ | 事件 | 小故事與選擇（約 120 個，依海域分配） |
| 火 | 營地 | 休息回復；可以和隊友夜談（加深羈絆） |
| 村 | 村落 | 交易、委託、情報；被霧吞掉一半的村子會有特別劇情 |
| 遺 | 遺跡 | 解謎、世界觀碎片、公會的紀錄 |
| 測 | 測繪點 | 完成測繪小遊戲 → 這一區永久保留，並得到測繪度 |
| 王 | 島主 | 首領戰；打倒後島嶼完成 |

- **補給**
  - 糧食：每走一格扣 1；扣光以後，每一格全隊扣體力，士氣下降。
  - 燈油：點燈可以看清周圍兩格、看穿霧中的陷阱。
  - 墨水：測繪與部分技能會用到。
  - 出航前在港口決定要帶多少；船的貨艙決定上限。
- **霧會回來**：沒有測繪的區域，離開島以後會重新被霧蓋住，下次來地形可能改變。完成測繪的區域永遠保留，下次可以直接傳送到那裡。
- **測繪小遊戲**（從《千秋硯》的描字延伸）：沿著海岸線和山脊，用手指描出這一區的輪廓；描得越準，測繪度越高，還可能發現隱藏地點。

### 4.2 航海
- 港口與島嶼之間以「航線」相連，出航會遇到 1～3 個海上事件：暴風、漂流的木箱、海怪、其他船隻。
- 船可以改造：貨艙（補給上限）、船帆（減少航海事件的負面效果）、船首像（特殊能力，例如在霧中看得更遠）。

### 4.3 戰鬥
- **回合制**，沿用《千秋硯》的戰鬥引擎與畫面（行動順序、血條、命中效果），改成**前後兩排站位**：
  - 我方、敵方各 2 排 × 3 格。
  - 近戰只能打前排；遠程、法術可以打後排。前排倒下，後排才會露出來。
  - 每回合可以花一個行動「換位」。
- **六種元素**：潮、焰、風、石，四個互剋一圈（潮剋焰、焰剋風、風剋石、石剋潮）；另外星與影互剋。
- **地形效果**（依戰鬥發生的格子而定）

| 地形 | 效果 |
|---|---|
| 霧中 | 雙方命中率下降；燈油可以抵銷 |
| 潮間帶 | 每三回合漲潮一次，前排角色會被推到後排 |
| 高地 | 我方遠程傷害提高 |
| 森林 | 第一回合偷襲機率提高 |
| 遺跡 | 星與影的技能威力提高 |

- 沿用《千秋硯》的首領蓄力、第二階段、敵人分工（補、反、盾、召）、特殊勝利條件。
- **士氣**：連勝、在營地休息、隊友羈絆會提高士氣（傷害與爆擊加成）；斷糧、隊友倒下會降低。

### 4.4 隊伍與成長
- 最多 4 人出戰（主角必定在內），其餘在船上待命。
- **六種職業**

| 職業 | 定位 | 代表技能 |
|---|---|---|
| 製圖師（主角） | 輔助、控場 | 「標記」：標出敵人弱點；「速寫」：複製敵人上一招 |
| 劍士 | 前排輸出 | 「破浪斬」：攻擊並把敵人推到後排 |
| 守衛 | 前排坦克 | 「錨」：替後排擋下一次攻擊 |
| 射手 | 後排輸出 | 「穿霧箭」：無視霧中命中下降 |
| 巫醫 | 治療、解狀態 | 「海草藥」：全隊回復；「驅邪」：解除詛咒 |
| 吟遊詩人 | 增益、士氣 | 「戰歌」：全隊士氣提升 |

- **等級**：打怪與完成島嶼得到經驗。
- **天賦樹**：每人一棵小天賦樹（約 12 個節點），兩條路線二選一，例如劍士走「連擊」或「重擊」，讓同一個角色有不同玩法。
- **羈絆**：營地夜談、事件選擇、個人任務提升；滿級解鎖合擊與個人結局台詞。

### 4.5 裝備與製作
- 每人 3 格：武器、防具、飾品。
- 素材從島上採集與戰鬥掉落；在港口的鐵匠打造。配方要先找到「圖紙」（藏在寶箱與遺跡裡）。
- 稀有度：普通、精良、傳說；傳說裝備各有一段小故事。

### 4.6 委託與勢力
- 酒館的告示板每次回港更新 3～5 個委託：討伐、護送、尋物、測繪某一區。
- 勢力委託會提高該勢力聲望、降低對立勢力聲望。
- 聲望分 5 級，影響商品、船的改造、可以招募的隊友，以及結局。

### 4.7 港口建設
- 主港「燈塔港」一開始只有酒館和一間破船塢。
- 用探索得到的資源修建：

| 設施 | 功能 |
|---|---|
| 酒館 | 委託、情報、招募隊友 |
| 鐵匠 | 打造與強化裝備 |
| 船塢 | 改造船隻 |
| 製圖室 | 提高燈油、墨水上限；測繪輔助 |
| 市場 | 買賣，商品依勢力聲望變化 |
| 天文台 | 解鎖下一片海域的航線 |
| 紀念碑 | 記錄被霧吞掉的島與人（收集要素） |

- 每升級一次，港口的背景圖會變得更熱鬧（同一張圖的 3 個階段）。

### 4.8 總地圖與收集
- 所有島嶼拼成一張大地圖；完成測繪的區域會以繪本風格上色。
- 玩家可以在地圖上**標註與命名**自己發現的地點（例如「第一次迷路的海灣」）。
- 收集要素：地圖完成度、怪物圖鑑、傳說裝備、被遺忘的故事（遺跡碎片）。
- 完成時可以把總地圖存成一張圖片分享。

### 4.9 難度（隨時可以在設定裡切換，不影響結局）
| 難度 | 敵人強度 | 補給消耗 | 霧會不會回來 | 其他 |
|---|---|---|---|---|
| 悠閒 | 0.7 倍 | 減半 | 不會 | 戰敗可以直接重來 |
| 標準 | 1 倍 | 正常 | 會 | — |
| 困難 | 1.3 倍 | 正常 | 會，而且更快 | 首領多一個階段 |

另外有三個可以單獨開關的項目：補給消耗、霧回歸、戰鬥速度。

## 6. 美術規格

## 10. 風險與對策

| 風險 | 對策 |
|---|---|
| 系統太多、範圍越做越大 | 嚴格照階段做；M1 只驗證「探索＋補給＋戰鬥」好不好玩，不好玩就先調整，不往下做 |

| 補給壓力讓人挫折 | 難度選項：「悠閒」模式補給消耗減半、霧不會回來 |
| 手機上六角格太小、難點 | 地圖可以拖曳、放大；格子最小 44 像素 |

## 12. M1 雛形規格

- 資料夾：`畫海人/`（和《千秋硯》並列，可以用網址或單機啟動）
- **流程**：標題（選難度）→ 序章（漁島、霧、母親的書，約 2 分鐘）→ 港口（用銀貝買補給、貨艙有上限）→ 航海事件 1 個 → 島嶼「低語礁」→ 打倒霧眼拿到鑰匙 → 打倒燈守 → 繼續探索或回登陸點返航 → 結局（依測繪度）與結算
- **島嶼**：5×5 六角格。固定：起點、首領、2 個測繪點、1 個營地；隨機：戰鬥、霧眼、寶箱、事件、遺跡。每次重玩配置都不同
- **隊伍**：墨里（製圖師）、阿潮（劍士）、蓮笙（巫醫），各 3 個技能
- **敵人**：10 種（含霧眼精英「溺者之影」與島主「燈守」，燈守有第二階段）
- **戰鬥**：兩排站位、換位、六種元素、地形（霧中、潮間帶、高地）、士氣
- **補給**：糧食（每步 1）、燈油（點燈時每步 1，看得更遠、抵銷霧中命中下降）、墨水（測繪與部分技能）
- **測繪**：用手指沿著海岸線描，描得越準測繪度越高
- **美術**：只用顏色、圖形與文字；聲音由程式合成（海浪、霧中低語、筆畫聲）
- **驗收**：手機上 15 分鐘內玩完一輪；自動試玩機器人能從頭玩到結算

## 13. M2 第一海域規格（v0.1）

- **流程**：序章 → 港口 ⇄（海圖選島 → 航海事件 → 島嶼 → 回港結算）→ 三座島都完成後，第一章結局
- **三座島**

| 島 | 大小 | 祕密 | 首領 | 遺跡線索（首領弱點） |
|---|---|---|---|---|
| 低語礁 | 5×5 | 燈塔守等了五十年的女兒「汐」 | 燈守（焰→影） | 星屬性 |
| 晨忘島 | 6×6 | 村人鑄鐘求霧讓他們忘掉海難，從此每天忘記昨天 | 晨鐘（石→影） | 風屬性（歌聲） |
| 沉船灣 | 7×6 | 阿潮父親的船「海燕號」；霧穿上了船長的雨衣 | 霧中的船長（潮→影） | 阿潮的攻擊 |

- **第一章的伏筆**：海燕號的航海日誌——父親跟著「一位女畫師的筆光」去了霧心，日誌最後畫著母親的記號（筆尖是一顆星）
- **隊友**：小鈴（吟遊詩人，風屬性）在晨忘島的村子加入；技能「戰歌」（全隊士氣 +12）、「回聲」、「搖籃曲」
- **港口設施**：碼頭、海圖一開始就有；完成低語礁後開放酒館、鐵匠；完成晨忘島後開放船塢
- **素材**：10 種（漂流木、霧苔、鹽晶、燈芯、珊瑚枝、鐘銅、褪色羽、鏽鐵、船帆布、夜光珠），打怪與寶箱取得，不佔貨艙
- **裝備**：每人 3 格（武器、防具、飾品），共 17 件；要先有圖紙（一開始會 6 張，其他在寶箱、首領、委託）
- **委託**：13 個（擊退、帶回素材、測繪度），一次最多接 2 個
- **船塢**：貨艙 40→55→70、補好的船帆（航海損失減半）、霧燈船首像（登島時看得更遠）
- **重訪島嶼**：測繪過的格子永久保留；其他內容每次重新隨機；第一次是普通結局的島，測繪度到 60% 再返航可以看到好結局；還沒打倒首領也可以先回港
- **遺跡小遊戲**：每座島的遺跡改成跟島上故事有關的小遊戲。低語礁「燈號」（燈塔照順序亮燈，照樣點回去，三輪）、晨忘島「門牌」（翻牌，把村人名字和他家的門配對，翻的次數有限）、沉船灣「航海圖」（點碎片轉 90 度，把撕碎的航海圖轉正，次數有限）。解開：首領弱點＋獎勵（墨水與該島素材），只拿一次；解不開：一樣得知弱點，下次來可以再試。難度設定會改變長度與容錯
- **畫面**：配色改為深海色調（深藍黑、冷光青綠，只有燈火與筆光是暖金色）；背景有緩慢旋轉的羅盤方位線、等深線波紋與漂浮的光點；面板與按鈕加上四角細框、內框細線、菱形與海平線分隔
