# 《畫海人》批次生圖說明

用你電腦上的 ComfyUI 產生劇情動畫的插圖。工作流放在 `畫海人/tools/生圖/workflows/`（新版 6 步）；這個資料夾不存在時，改用《千秋硯》的 `千秋硯/tools/生圖/workflows/`。
第一次設定（安裝 Claude Code、下載儲存庫、`pip install pillow`、確認模型）和《千秋硯》一樣，見 `千秋硯/tools/生圖/README.md` 第一節。

畫風（2026-10-11 定案）：**動畫電影風**。中世紀歐洲的群島，整體灰暗（灰、深藍、苔綠），只有燈火、爐火、夕陽和筆光是暖金色；人物是乾淨的動畫上色。
設計草案：專案檔案 `畫海人/畫風與角色定稿草案.md`。

---

## 三個步驟

每一步都先**打開 ComfyUI**（網址預設 `http://127.0.0.1:8188`），再在你電腦的 Claude Code 裡說出那一步的話。

### 第一步：試畫（9 張）

> 執行《畫海人》的試畫

```bash
python 畫海人/tools/生圖/batch.py --list 清單_試畫.json
```

三種畫風（A 動畫電影風、B 厚塗奇幻、C 繪本水彩＋動畫人物）× 三個場景（港口、公會大廳、墨里）。
畫完打開 `畫海人/tools/生圖/審圖.html`，告訴 Claude 你選哪一種。選 A 以外的話，Claude 會把劇情清單和角色清單的畫風換掉。

### 第二步：角色定稿（44 張）

> 執行《畫海人》的角色定稿

```bash
python 畫海人/tools/生圖/batch.py --list 清單_角色.json
```

11 個角色，每人 4 張候選立繪（`立繪_墨里_候選1`～`候選4`）。看審圖頁，告訴 Claude 每個人選哪一張，例如「墨里選 3、阿潮選 1」。
都不喜歡的話，說「墨里再畫 4 張」，Claude 會把種子往後挪再畫。外觀想改（髮型、衣服），直接說。

Claude 把選中的種子寫回 `清單_角色.json`、拿掉 `candidates`，再執行一次同一個指令，就會畫出正式的 `立繪_墨里`（和你選的那張一樣），之後的插圖拿它當參考圖。

### 第三步：劇情插圖（174 張）

> 執行《畫海人》所有還沒畫的圖

```bash
python 畫海人/tools/生圖/batch.py
```

已經畫過的會自動略過，中途停掉、下次再跑也沒關係。不滿意的圖說「幕_碼頭的背影 重畫」：

```bash
python 畫海人/tools/生圖/batch.py --names 幕_碼頭的背影 --force --seed-offset 1
```

（`--seed-offset` 每次加 1，就會畫出不同的版本。）審完之後說「把圖上傳並合併」。

### 第四步：怪物、裝備、物品、場景、海圖（約 370 張）

劇情插圖畫完以後再開始。設計草案：專案檔案 `畫海人/場景怪物道具生圖草案.md`。

| 清單 | 內容 | 張數 | 存在哪裡 |
|---|---|---|---|
| `清單_怪物.json` | 每一種怪物（`怪_霧蟹`） | 160 | `img/enemy/`，512×512 |
| `清單_裝備.json` | 每一件裝備（`裝_海鷗羽筆`） | 115 | `img/gear/`，256×256 |
| `清單_物品.json` | 素材、補給、道具（`物_漂流木`） | 55 | `img/item/`，256×256 |
| `清單_場景.json` | 港口、設施、各島的遠景（`景_酒館`）、海圖每一頁（`圖_淺灘`） | 39 | `img/place/`，1600 與 800 寬 |

照下面的順序，一次說一句：

1. **試畫 12 張**，先確認畫風和透明背景：

   > 執行《畫海人》第四步的試畫

   ```bash
   python 畫海人/tools/生圖/batch.py --names 怪_霧蟹,怪_燈蛾,怪_溺者之影,怪_燈守,裝_海鷗羽筆,裝_珊瑚刃,裝_珊瑚甲,物_漂流木,物_鹽晶,物_藥草,景_港口,景_低語礁
   ```

   腳本每張會寫「（透明背景）」或「（注意：輸出沒有透明通道）」。沒有透明通道的話，告訴 Claude，改用「深藍灰色圓形底」的備案。
2. **首領和精英怪物**（58 張）：`python 畫海人/tools/生圖/batch.py --only enemy --rank 首領,精英`
3. **港口、設施、島嶼、海圖**（39 張）：`python 畫海人/tools/生圖/batch.py --only place`
4. **其他怪物**（102 張）：`python 畫海人/tools/生圖/batch.py --only enemy`
5. **裝備**（115 張）：`python 畫海人/tools/生圖/batch.py --only gear`
6. **素材、補給、道具**（55 張）：`python 畫海人/tools/生圖/batch.py --only item`

每一批畫完都看審圖頁，再說「把圖上傳並合併」。還沒畫的東西，遊戲照舊顯示文字，所以可以一批一批上線。

## 給 Claude 的操作備忘

- 清單：資料夾裡所有 `清單_*.json` 都會讀進來（畫風 `style`、角色外觀 `looks` 互相查得到；節點以 `清單_劇情.json` 為準）。標了 `"手動": true` 的清單（試畫、角色）只有用 `--list` 指定時才會跑；`--names` 可以指定任何清單裡的圖。
- `kind: "design"`：定稿圖。存在 `定稿/`（WebP，不裁切），**不放進遊戲、不上傳**（已列在 `.gitignore`）。原始 PNG 和其他圖一樣在 `原圖/`。
- `style`：指定用 `style` 裡哪一段畫風（沒寫就用 `kind`）。負向提示詞預設用 `negative`，畫風另有 `negative_<畫風名稱>` 時改用那一段（角色立繪用 `negative_design`，不排除明亮光線）。
- 新版工作流（Qwen-Image 2.1 + viggle-turbo v0.3 6 步 LoRA）不用 CFG，**負向提示詞實際上不起作用**；不要的東西要在正向描述裡講清楚（例如「Indoors only」「single character」）。
- 畫風提示詞只寫畫法、色調和光線，**不要寫任何場景物件**（房子、碼頭、船……），否則會跑進不相干的畫面（第一輪試畫的室內出現了港口的房子）。場景物件寫在每張圖自己的描述裡；室內場景寫明「Indoors only」。
- 角色立繪：明亮、色彩清楚、細節多，不套用場景的暗色調；每人的專屬配色與小配件寫在 `清單_角色.json` 的 `themes`，依角色屬性設計（星、潮、影、風、焰、石）。
- `chars`：插圖裡出現的主要角色，會自動在描述最後接上 `清單_角色.json` 的固定外觀。新增有主要角色的插圖時，描述裡用「the girl」「the woman」等代稱，外觀不要另外寫，以免和固定外觀打架。
- `ref`：參考圖（圖生圖），可以是一個名稱或一串名稱。插圖（正方形）或好幾個角色時，腳本會把立繪並排貼在正方形的淺灰底上再送出。用在臉看得清楚的近景；遠景、背影用 `chars` 就好。描述裡要寫「Keep their faces, hair and clothes the same as the reference」。
- `candidates`：還沒選定的圖，先畫 N 張候選（名稱加 `_候選1`…，種子連續）。角色種子間隔 10，不會互相重疊。
- 輸出：劇情插圖存成 `畫海人/img/scene/名稱-1200.webp`、`名稱-700.webp`，並更新 `畫海人/img/manifest.json`。
- 上傳前執行 `node 畫海人/tools/check.mjs`：會檢查所有清單的名稱不重複、`chars` 都有固定外觀、`ref` 都在清單裡、劇情動畫用到的插圖都在清單裡。只提交 `畫海人/img/` 與清單的變更。
- 怪物、裝備、物品、場景（第四步）：清單由遊戲資料對出來，`check.mjs` 會檢查 `data.js` 的每一種怪物、每一件裝備、每一種素材、每一座島都在清單裡（新增怪物或裝備時，也要在清單加一張）。遊戲用 `js/art.js` 讀 `img/manifest.json`，有圖才顯示，名稱前綴：怪_、裝_、物_、景_、圖_。
- 怪物、裝備、物品的畫風比場景亮、輪廓清楚（縮小以後才看得清楚），透明背景；怪物依屬性加主色調（潮＝青綠、焰＝橘紅、風＝淡綠白、石＝土黃灰、星＝金銀、影＝紫灰）。`公會長` 用 `chars` 接上固定外觀。
- 場景（`景_`）不要有人：畫風句一開頭就講「沒有人」（第三輪審圖學到的）。
- 島嶼地圖的六角格不用生圖：地形紋理由 `js/terrain.js` 用程式畫。
- 畫風要點：中世紀歐洲（石頭與木頭的房子、石板屋頂、帆船、拱窗），不要東方元素（紙燈籠、寶塔、和服），燈寫成「iron-framed oil lantern」。畫面裡不要出現文字（寫字的地方寫成抽象的線條或圖案）。
