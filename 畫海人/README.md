# 《畫海人》（五片海域與結局都已完成）

世界被霧吞沒，只有被畫進地圖的地方才會留下來。目前五章全部可以玩到結局：第一章「淺灘」（三座島）、第二章「珊瑚環礁」（四座島）、第三章「焰之群島」（四座島）、第四章「北霧海」（四座島）、第五章「霧心」（五座島，最後的抉擇與四種結局）。通關後還有四座隱藏島和「第六頁・墨潮島」。

美術：角色立繪、劇情插圖、怪物、裝備、道具、港口與海圖的圖大部分已經放進遊戲；還沒畫好的圖，遊戲會先用程式畫的剪影或色塊代替。

## 怎麼開
- **網址**：發布到 GitHub Pages 後，打開 `畫海人/index.html`。
- **電腦單機**：雙擊 `單機啟動.bat`（需要 Python），會自動打開瀏覽器。
- 不能直接雙擊 `index.html`（瀏覽器會擋住讀檔）。

## 內容
- 第一章「淺灘」：低語礁（燈塔）→ 晨忘島（鐘樓，小鈴加入）→ 沉船灣（海燕號），完成沉船灣就是第一章結局
- 第二章「珊瑚環礁」：第一章完成後，到港口的「天文台」打開第二頁海圖。千帆市（當鋪，費米加入）→ 雙影嶼（測量所）和珠母潟湖（湖心）可以自己選順序 → 帳房島（白色的塔，費米要做一個選擇），完成帳房島就是第二章結局
- 第三章「焰之群島」：第二章完成後，再去「天文台」打開第三頁海圖。紅帆港（帆房，葛蘿加入）→ 鐵喉礦坑（很暗）和鍛火嶼（噴氣口）可以自己選順序 → 紅岬（攻上去前要選：跟紅帆強攻，或拿商會通行令走正門），完成紅岬就是第三章結局
- 第四章「北霧海」：第三章完成後，去「天文台」打開第四頁海圖。灰燈渡（老洛加入）→ 鏡冰湖和斷桅灣可以自己選順序 → 霧門（攻上去前選三條路：守霧人的祕道、商會的破冰船、紅帆的火藥），完成霧門就是第四章結局。冰面格會一直滑；「聲」格是霧中低語，有真有假
- 第五章「霧心」：第四章完成後，去「天文台」打開第五頁海圖（霧子加入）。忘人港（嘎嘎加入）→ 無名島和祈願塔可以自己選順序 → 畫室 → 霧心（公會長三階段）→ 最後的抉擇：晴海、與霧同行、自由之海，或真結局「留白」（三方聲望都到「信任」、8 個隊友的心願完成、測繪夠完整）→ 尾聲與製作名單。通關後回到港口繼續玩，到天文台可以重新做最後的抉擇
- 通關後的內容：四座隱藏島（醉鯨礁、沉金船、紅帆藏寶島、冰下船塢，線索分別在酒館、市場、黑市、船塢）；酒館的隱藏委託收集五片殘片，拼成「第六頁・墨潮島」（16×16 的大地圖、五區、連鎖的通關條件）；天文台的「小遊戲間」可以重玩解開過的遺跡小遊戲
- 勢力聲望（第三章開始）：商會、紅帆，第四章再加上守霧人。酒館的勢力委託、事件、紅岬前的選擇都會改變；商會越信任，市場收購價越好；紅帆越信任，黑市賣的東西越好
- 火山地形：熱地格走過會掉血；噴氣口每走 3 步噴一次火
- 隊伍：九個人（墨里、阿潮、蓮笙、小鈴、費米、葛蘿、老洛、霧子、嘎嘎），一次最多 4 人出戰，其他人在船上待命，在「隊伍」裡換人
- 港口：碼頭（補給）、海圖（選島出航）、酒館（委託按章分頁、流言、潮汐骰）、鐵匠（打造與升級裝備，要玩「打鐵」小遊戲）、船塢（改造船，要玩「釘船板」；船況與修船）、天文台（下一片海域、小遊戲間）、市場（行情、買賣素材、舶來品）、黑市（紅帆港完成後：換貨、紅帆牌桌、走私）。港口每天可能有突發事件
- 訓練：營地、航行中的甲板可以玩訓練小遊戲回復士氣
- 遺跡小遊戲：低語礁「燈號」（記住燈亮的順序）、晨忘島「門牌」（翻牌配對名字和門）、沉船灣「航海圖」（把碎片轉正）、千帆市「天秤」（只看秤往哪邊歪，放砝碼讓兩邊一樣重）、雙影嶼「對照」（找不同）、珠母潟湖「潮閘」（撥閘門把水引到珊瑚）、帳房島「航線」（一筆畫連起所有浮標）、紅帆港「旗語」（照密碼表讀旗子）、鐵喉礦坑「礦車」（推箱子）、鍛火嶼「鍛火」（看準爐溫敲下去）、紅岬「熔岩」（關燈遊戲）、灰燈渡「低語」（找出說謊的聲音）、鏡冰湖「冰滑」、斷桅灣「密碼鎖」、霧門「光路」、忘人港「褪色的畫」（滑塊拼圖）、無名島「數織」、祈願塔「搬鐘」（河內塔）、畫室「墨線」、霧心「四色地圖」，墨潮島另有「海岸線」「撈網」「星圖連線」。解開了多拿獎勵，解不開也看得到首領弱點
- 劇情動畫：遊戲開場、每座島第一次登島、每一章的開場與結尾、結局，會自動播放圖片與文字，右上角可以略過；看過的可以在「設定 → 回顧劇情」重看。插圖已經放進大部分，墨潮島的 10 張還沒畫，先用程式畫的剪影
- 人物登場：11 位主要人物第一次開口時，對話上方會淡入登場插圖；戰鬥與隊伍畫面的我方頭像是角色半身小圖
- 測繪過的格子會永久留下；上次畫得不夠準的測繪點，下次來可以重畫補上。完成過的島可以再去，測繪度 60% 以上會看到更好的結局

## 檔案
- `js/data.js`：角色、技能、敵人、道具、素材、裝備、船塢、委託
- `js/islands.js`：各島的地圖設定、事件、劇情文字、航海事件、章節結尾
- `js/explore.js`：六角格地圖、霧、補給、格子事件
- `js/battle.js`：前後兩排的回合制戰鬥
- `js/port.js`：港口（碼頭、海圖、酒館、鐵匠、船塢、天文台、市場、黑市）
- `js/survey.js`：測繪小遊戲
- `js/puzzle.js`：遺跡小遊戲（每座島一種）
- `js/cinema.js`：劇情動畫的播放器（還沒有插圖時用剪影場景）（動畫的文字在 `js/islands.js` 的 `CINEMA`）
- `js/story.js`：每座島的隊友事件、營火夜談、重訪好結局島嶼的「之後的樣子」
- `js/hidden.js`：四座隱藏島
- `js/inkisle.js`、`js/inkplay.js`：第六頁・墨潮島
- `js/forge.js`：打造小遊戲（打鐵、釘船板）
- `js/gamble.js`：潮汐骰、紅帆牌桌
- `js/training.js`：訓練小遊戲
- `js/art.js`：讀取生好的圖（沒有圖時顯示替代的樣子）
- `js/terrain.js`：島嶼格子的地形紋理
- `js/main.js`：標題、序章、出航、回港、選單、隊伍與裝備
- `tools/check.mjs`：資料檢查。改了 `data.js` 或 `islands.js` 以後執行 `node 畫海人/tools/check.mjs`
- `tools/生圖/`：生圖清單（劇情、角色、怪物、裝備、物品、場景）與 `batch.py`，說明見 `tools/生圖/README.md`（在自己電腦開 ComfyUI 執行，圖會放進 `img/`）
- 企劃書：`../奇幻冒險企劃/遊戲架構企劃書.md`
