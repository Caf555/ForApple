# 《畫海人》M2 第一海域「淺灘」

世界被霧吞沒，只有被畫進地圖的地方才會留下來。這是第一章「淺灘」：三座島、港口、委託、裝備打造。美術先用色塊和文字代替。

## 怎麼開
- **網址**：發布到 GitHub Pages 後，打開 `畫海人/index.html`。
- **電腦單機**：雙擊 `單機啟動.bat`（需要 Python），會自動打開瀏覽器。
- 不能直接雙擊 `index.html`（瀏覽器會擋住讀檔）。

## 內容
- 三座島：低語礁（燈塔）→ 晨忘島（鐘樓，小鈴加入）→ 沉船灣（海燕號），完成沉船灣就是第一章結局
- 港口：碼頭（補給）、海圖（選島出航）、酒館（委託）、鐵匠（用素材打造裝備）、船塢（加大貨艙、船帆、船首像）
- 遺跡小遊戲：低語礁「燈號」（記住燈亮的順序）、晨忘島「門牌」（翻牌配對名字和門）、沉船灣「航海圖」（把碎片轉正）。解開了多拿獎勵，解不開也看得到首領弱點
- 劇情動畫：遊戲開場（霧之群島的由來）、三座島第一次登島、第一章結尾，會自動播放圖片與文字，右上角可以略過；看過的可以在「設定 → 回顧劇情」重看。現在先用程式畫的剪影，生好插圖以後會自動換上
- 測繪過的格子會永久留下；完成過的島可以再去，測繪度 60% 以上會看到更好的結局

## 檔案
- `js/data.js`：角色、技能、敵人、道具、素材、裝備、船塢、委託
- `js/islands.js`：三座島的地圖設定、事件、劇情文字、航海事件
- `js/explore.js`：六角格地圖、霧、補給、格子事件
- `js/battle.js`：前後兩排的回合制戰鬥
- `js/port.js`：港口（碼頭、海圖、酒館、鐵匠、船塢）
- `js/survey.js`：測繪小遊戲
- `js/puzzle.js`：遺跡小遊戲（燈號、門牌、航海圖）
- `js/cinema.js`：劇情動畫的播放器與剪影場景（動畫的文字在 `js/islands.js` 的 `CINEMA`）
- `js/main.js`：標題、序章、出航、回港、選單、隊伍與裝備
- `tools/check.mjs`：資料檢查。改了 `data.js` 或 `islands.js` 以後執行 `node 畫海人/tools/check.mjs`
- `tools/生圖/`：劇情動畫插圖的生圖清單 `清單_劇情.json` 與 `batch.py`（用法和《千秋硯》的生圖相同：在自己電腦開 ComfyUI，執行 `python 畫海人/tools/生圖/batch.py`，圖會放進 `img/scene/`）
- 企劃書：`../奇幻冒險企劃/遊戲架構企劃書.md`
