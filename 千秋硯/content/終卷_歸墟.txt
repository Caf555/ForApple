// 終卷〈歸墟〉 時間的盡頭
// 回一〈歸墟〉
// 歸墟：《列子・湯問》裡，天下所有的水最後都流進去的無底之谷。在本作裡，是時間的盡頭——所有被蝕拿走的字，最後都沉在這裡。
// 回聲：各卷的人，在歸墟裡以「回聲」的樣子出現。回聲是他們寫下的、說過的、被拿走的東西聚成的影子。他們記得知墨，因為知墨的墨碰過他們。
// 終卷的結局（回五）：一、記得一切；二、溫柔的遺忘；三、補史人的代價；真結局〈千秋〉。
// 判定用的條件：羈絆 蘅、善終（無名客在各卷善終的次數）、動搖（無面書記在各卷動搖的次數）、修復率（史冊修復率）、終局的論辯。
// ════════════════════════════════════════

// ──────────── 回一〈歸墟〉 ────────────
// 入口：手冊最後一頁，用光燒出來的「歸墟」。出發前，爸爸寫了一封給祖父的信。知墨帶著三封信：曾祖父的、祖父的、爸爸的。
// 小雨撕下的那一頁：她照著蘅說的，寫了「蘅」這個字。「姊姊，如果妳忘記自己的名字，就看這裡。」
// 回聲：蒂娃、楊、石頭（卷一）。石頭那封寫給阿母的家書，沒有寄到金門，沉在歸墟裡。
// 可以影響的小字：石頭的家書，要怎麼辦（終.信 送／念／放——放：石頭把它摺成紙船，放在歸墟的水上，「所有的河都流到這裡。那從這裡，應該也流得回去」）。
