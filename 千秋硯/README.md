# 千秋硯（試玩版 v0.4）

致敬《軒轅劍》與《仙劍奇俠傳》的網頁文字角色扮演遊戲，手機直向優先。

**目前內容：** 序卷〈府城〉＋ 卷一〈大員〉回一〈新港的字〉、回二〈被送走的祭司〉、回三〈甘蔗田的火〉、回四〈鹿耳門的潮〉、回五〈熱蘭遮的最後一夜〉——卷一完結（約 5～7 小時）

## 怎麼玩

本遊戲由多個檔案組成，**必須透過網址開啟**（直接在手機上點開 `index.html` 檔案會無法載入劇本）。

- **GitHub Pages：** 在儲存庫的 Settings → Pages 啟用後，網址會是
  `https://<帳號>.github.io/<儲存庫>/千秋硯/`
- **電腦本機測試：** 在儲存庫根目錄執行 `python3 -m http.server`，再開啟 `http://localhost:8000/千秋硯/`

在手機瀏覽器中選「加入主畫面」，就能像 App 一樣全螢幕遊玩，而且離線也能玩。

## 檔案結構

| 路徑 | 內容 |
|---|---|
| `index.html` | 遊戲入口 |
| `content/*.txt` | 劇本（中文劇本語法，見 `文字RPG企劃/劇本語法說明.md`） |
| `js/data.js` | 角色、技能、敵人、道具、配方、史卷等資料 |
| `js/script.js` | 劇本解析器 |
| `js/runner.js` | 劇本執行器 |
| `js/battle.js` | 戰鬥引擎（回合制、五行、合擊、陣法、封靈） |
| `js/debate.js` | 論辯戰與譯字小遊戲 |
| `js/hub.js` | 時之書齋、選單、存讀檔 |
| `js/state.js` | 遊戲狀態、數值、存檔碼 |
| `js/audio.js` | 程式合成的音樂與音效 |
| `tools/check.mjs` | 劇本檢查工具：`node tools/check.mjs` |

設計文件在 `文字RPG企劃/`。
